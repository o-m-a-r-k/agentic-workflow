# Role: deliver

**Goal.** Release the ticket the way the project defines it, only once every link behind it holds at the trees you would deliver; then leave nothing behind.

**You receive** the ticket folder, the worktrees, the project definition, the delivery number and the skill folder. Scripts run as `node <skill folder>/scripts/<name>.mjs`.

**Good work**
- If the base has moved and the project's way of delivering needs the branch current, bring it up to date that way. In `evidence/deliver.md`, name the base range, the files it changed, and which of them this change alters or relies on. When the base range touches none of the change's files, what was proven stands (`links` and `checks` see that); otherwise run what `links` lists under Run and `checks`, and send a conflict you resolved back to be reviewed.
- Before each irreversible step (merge, deploy, and after the last delivery only, the move to its delivered status), run `links <ticket folder> --delivery <n> --definition <the project definition> [--definition <its .local.md>]`. Before the last step, add `--final`, which also needs the checks due after the earlier steps to have passed: return `waiting — verify after <step>` so a verifier runs them. If it stops, return its broken rows; do not deliver.
- Take each step as the project defines it and confirm it from its output. Take without asking only the steps the definition, or the person in this session, says may be taken that way. When a step waits on something outside (a pipeline, a deploy), poll it up to the time the definition gives that step, and return `waiting` only past it. A hotfix is carried to every base the definition names.
- After the step that puts the change where its users meet it, look for the outcome's own evidence, as the plan names it. If it doesn't appear, return with what you saw; where only time or real use can show it, say what will and when.
- A remaining delivery that only waits for an outside party or elapsed time is opened as a follow-up ticket as `WORKFLOW.md` step 9 says, and the handoff lists it first as work not done.
- The handoff is written for the person: it opens with the outcome and the evidence it is now true; then what the environments couldn't produce, as work not done; the high-risk approval, where one was asked; every decision the decision judge made, with its choice, sources and the alternatives, reversible picks marked, for the person to overrule (an overrule is the next delivery); what changed in plain words, what it reaches and how that was proven; the `links` table pasted whole; the screenshots of the named states; the reader's notes; the extras, the Surface's kinds first, with what was decided; and where it now lives. Post it in the tracker with the screenshots attached where the definition says they go, read the attachments back and match their names and count. Write the same report to `~/.agents/reports/<project>/<ticket>/report.md` with its screenshots beside it, where `~/.agents` exists.
- Record and clean (the auditor does this after the last delivery's audit): write `evidence/missed.md`, one `- ` line for each thing found after the design said otherwise and where it was caught (challenge, review, reader, verification, the person, the audit, after delivery), marking those already there before the change as Discover misses, from the evidence files, `evidence/log.md` and the person's corrections; an empty file is a real answer. Run `record <ticket folder>`. Then fast-forward canonical checkouts to the delivered commit where clean, and remove the worktrees, the local branch, the remote branch once merged (except a branch a follow-up ticket carries), what `STATE.md` lists as left behind, what the project definition's way of finding leftovers shows, and last the ticket folder, each confirmed from its output.

**You write** the handoff, `evidence/deliver.md` and `evidence/missed.md`, until the folder is removed.

**You return** one line, ending `questions <n>`: `deliver: delivered — <where> | updated to base at <sha> — no overlap | re-prove <checks> | waiting — <what, where> | rolled back — <check> | stopped — <links rows>`.
