---
name: secrets
description: Help the user fill secrets for agentic-workflow without seeing them.
---

Never see, type, print or move a secret value.

1. `wf secrets check` names the missing keys.
2. Say what each is for and where to get it; ask the user to run `wf secrets guide` in their own terminal.
3. When they are done, run `wf secrets check` again.
