# I-37: Codex plugin skills are invisible to workflow skill discovery

- **Class:** onboarding
- **Fixed in:** 0.5.3
- **Test:** `scenarios/onboarding.test.mjs` (Codex plugin skills follow the enabled installed version, not the newest cached version)

## Failure

Skill lookup checks Codex project and user folders but never installed enabled Codex plugins, causing available plugin skills to be reported missing.

## Fix

Discover Codex plugin skills from the native installed enabled version list, including namespaced skills. Cached-only and disabled versions never count; ambiguous or unreadable installed state refuses.
