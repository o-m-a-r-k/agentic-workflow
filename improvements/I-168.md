# I-168: Preserve unreached review obligations across a clean base merge

- **Class:** engine
- **Fixed in:** 0.7.30
- **Test:** `scenarios/fix-0730c.test.mjs`

## Failure

A code-review closure named a concrete unreached native verification. After wf base merge invalidated that review, the next implementer bundle had reviewClosureFile:null and omitted the notReached scope. Owner detected the missing goal, stopped the just-started role before edits and recorded the proof gap explicitly for a fresh handoff. Carry these obligations across base invalidation so implementation cannot silently repeat already passing checks.

## Fix

unreachedBefore reaches implementers too, worded for them.
