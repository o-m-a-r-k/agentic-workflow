# I-44: Adopted attempts cannot launch models configured on a later committed base

- **Class:** engine
- **Fixed in:** 0.5.5
- **Test:** `scenarios/runtime-models.test.mjs`

## Failure

Doctor validated current configuration while launch used the admission pin. Base merge did not refresh it. Resume called a never-launched reviewer running.

## Fix

Record an owner-authorized separate execution commit. Resolve only model/effort from it, preserve admission rules and old handoffs, reject arbitrary overrides, diagnose actual attempt pins and report launch states.
