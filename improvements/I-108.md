# I-108: A valid Codex patch with an empty context line is refused as evidence

- **Class:** guard
- **Fixed in:** 0.7.4
- **Test:** `scenarios/fix-074-lessons.test.mjs` (every patch Codex applies yields its targets)

## Failure

The Codex apply_patch parser accepts a hunk line only when it starts with a space, + or -. An Update hunk with a bare empty context line makes it throw, and the guard fails closed with the evidence refusal on a patch that touches no evidence; Codex itself applies the same patch.

## Fix

The native patch parser is a port of the grammar the agent runtime applies (empty context lines, End of File markers and the blank lines after them, white space around headers and boundary lines, heredocs, a stray second End Patch line), checked against the runtime on over 10,000 fuzzed patches; a patch it refuses to parse is still refused, and the guard says an unreadable payload is malformed instead of blaming the evidence folder.
