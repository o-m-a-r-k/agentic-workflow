# I-108: A valid Codex patch with an empty context line is refused as evidence

- **Class:** guard
- **Fixed in:** 0.7.4
- **Test:** `scenarios/fix-074-lessons.test.mjs` (every patch Codex applies yields its targets)

## Failure

The Codex apply_patch parser accepts a hunk line only when it starts with a space, + or -. An Update hunk with a bare empty context line makes it throw, and the guard fails closed with the evidence refusal on a patch that touches no evidence; Codex itself applies the same patch. It was compared during development against the Codex release it was ported from; the scenario's table of patches runs through a real Codex binary when WF_TEST_CODEX=1, and a later Codex that accepts more is refused as malformed (safe) until the port is updated.
