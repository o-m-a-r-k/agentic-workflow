# I-82: Evidence inspect pagination resolves numeric from as a filesystem path

- **Class:** engine
- **Fixed in:** 0.6.3
- **Test:** `scenarios/evidence-pagination.test.mjs`
- **Regression of:** I-80

## Failure

The initial structured inventory and pointer inspection work when from is omitted. Any documented inspect call with --from 0 or --from 4096 fails with inspect needs a JSON pointer, nonnegative integer --from and --count. engine/cli.mjs READ_OPTIONS includes from and dispatch calls resolvePathOption before inspectEvidence; the numeric offset becomes an absolute path and fails integer validation. Required oversized frozen contract inspection cannot complete. Exempt numeric inspect pagination from path resolution, retain skills update from directory validation, and add a CLI scenario for zero and nonzero offsets.

## Fix

Preserve numeric inspection offsets while retaining skills source-directory path validation; remove accidental lesson inspection dispatch and test actual CLI zero and nonzero pages.
