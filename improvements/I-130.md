# I-130: A recurrence found after acceptance writes the lesson file of the pull-only main checkout

- **Class:** engine
- **Fixed in:** 0.7.9
- **Test:** `scenarios/lessons.test.mjs` (a new lesson matching an existing one)

## Failure

recur() writes the lesson's recurrence into its file wherever targetFor points; at acceptance (accepted) and after delivery (finished) that is the repository's main checkout, a tracked file nobody commits. The I-99/I-112 ledger-only exceptions cover only lessons the attempt itself added and repos it did not admit. Counting recurrences from review findings would make this frequent.

## Fix

A recurrence is recorded on the attempt and in the project's learned record (.workflow-maintenance/learned.jsonl), never written into a lesson file; wf lesson list shows the committed and learned counts together.
