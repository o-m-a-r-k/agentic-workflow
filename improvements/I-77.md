# I-77: Native reviewer stops after a successful complete reference read

- **Class:** template
- **Retired in:** 0.7.0
- **Refusals recorded:** none named

## Failure

A native reviewer ended incomplete, claiming a large design reference was still truncated, although its last shell output held the complete document with no truncation marker; the reference was not among the required full reads and indexed section reads were already allowed.

## Why it was retired

Obsolete: 0.7.0 removed required full-read documents with the read receipts; a reviewer that stops early is the I-69 case, fixed in 0.7.4.
