# I-161: Gate screenshot export collides across required steps

- **Class:** engine
- **Fixed in:** 0.7.20
- **Test:** `scenarios/fix-0720.test.mjs`

## Failure

wf0.7.13 export screenshots --gate refuses a passed gate when original and supplemental browser steps produce distinct hashes under the same source filename. gateFiles expands duplicate basenames using source only, which is also identical across steps. Include authoritative step identity or hash in presentation names; preserve source hash and safe exclusive no-follow export checks. Current task used the installed exportScreenshots API on read-only per-step views, without altering recorded state or evidence, to export each suite into its own folder.

## Fix

Screenshot titles are unique (step-qualified when source paths clash) and exports are numbered and sha-checked.
