# I-9: Tracker access is chosen at onboarding, with the trade-off stated

- **Class:** onboarding
- **Fixed in:** 0.3.0
- **Test:** `scenarios/tracker-mode.test.mjs` (doctor states the tracker mode trade-off; api mode needs its key; the readback says where it came from)

## Failure

The agent-driven connector route cannot produce a verifiable readback, and nobody was told when choosing it.

## Fix

The onboard skill asks how wf talks to the tracker (api recommended); `wf doctor` warns on connector mode and fails on a missing api key; `wf tracker mode`; readbacks are labelled agent-reported unless they are the host's saved tool result.
