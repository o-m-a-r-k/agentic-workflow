# I-150: Step passes from another attempt with the same key are not reused

- **Class:** engine
- **Fixed in:** 0.7.12
- **Test:** `scenarios/gate.test.mjs` (a pass another attempt recorded under the same key is reused; a step that keeps evidence, or a file outside its inputs that differs, reruns)

## Failure

Audit of 51 attempts: 163 reruns had a key another attempt had already passed (same inputs, runner and other repos' trees); reuse reads only the attempt's own runs.

## Fix

a step that keeps no evidence reuses a pass another attempt of the project recorded under the same key, when no package file outside its inputs differs; the record names the attempt
