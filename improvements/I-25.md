# I-25: Fix handoffs carry a pattern-sweep list; doctor fails without a reviewer model; flag doNotRun that excludes a repo the ticket now touches

- **Class:** template
- **Fixed in:** 0.5.0
- **Test:** `scenarios/impact.test.mjs`

## Failure

<ticket> retrospective: fix briefs targeted single findings, so the same defect pattern recurred across rounds (empty later page, failed Next, raw enum codes, card overflow, hard-coded constants, stale schema tests); the reviewer role had no model for five rounds and the Sonnet default let defects through that Opus found later; a plan doNotRun forbidding <project> test suites stayed in force after the ticket started changing the <project>, which let a stale public <project> test through. Changes: a fix handoff prints a required pattern-sweep list (grep targets for other instances) that the implementer must answer and the next reviewer checks; wf doctor fails when a reviewer or planner role resolves to no explicit model; wf criteria amend and wf handoff warn when a plan doNotRun or externalServices restriction names a repo or suite that the attempt's diff now touches; an amendment that adds endpoints, error codes or repos requires an explicit split-or-keep decision.

## Fix

A fix handoff while review findings are open needs --sweep: one structured pattern query per open finding, run by the engine and printed with its hits; the implementer answers each in a Sweep <id>: fixed|clean commit trailer and wf handoff reviewer refuses until it has; the next reviewer bundle lists each sweep with hits then and now. wf doctor fails when the planner or reviewer resolves to no Claude model. wf handoff and wf criteria amend warn when a plan doNotRun or externalServices entry names a repo or gate step the diff now touches. The split-or-keep decision is replaced by the impact addendum the amendment owes (I-26), since discovered work stays in the ticket.
