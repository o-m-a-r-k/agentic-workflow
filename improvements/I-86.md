# I-86: Resolve production prerequisites before asking the owner in investigations

- **Class:** template
- **Fixed in:** 0.7.4
- **Test:** `scenarios/fix-074-texts.test.mjs` (an investigation queries the read-only sources before asking the person for a fact)

## Failure

The Notion investigation asked the owner whether fikr had saved cost-center mappings even though established read-only Kubernetes and tenant database access was available. Investigation handoffs should check scoped Kong logs, production logs and stored tenant data before concluding a cause or asking the owner for discoverable facts.

## Fix

The work skill and the planner say to resolve an investigation's facts from the read-only sources before asking; a scenario pins the wording.
