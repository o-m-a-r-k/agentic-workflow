# I-86: Resolve production prerequisites before asking the owner in investigations

- **Class:** template
- **Fixed in:** 0.7.4
- **Test:** `scenarios/fix-074-texts.test.mjs` (an investigation queries the read-only sources before asking the person for a fact)

## Failure

An investigation asked the owner whether an application had saved some mappings, although read-only access to the cluster logs and the tenant database was available and held the answer. Investigation handoffs should consult the read-only sources (gateway and application logs, stored tenant data) before concluding a cause or asking the owner for a discoverable fact.

## Fix

The work skill and the planner say to resolve an investigation's facts from the read-only sources before asking; a scenario pins the wording.
