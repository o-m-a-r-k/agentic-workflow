# I-193: Improvement list says 'fixed in X' before X is published or installed

- **Class:** engine
- **Fixed in:** 0.7.27
- **Test:** `scenarios/improve.test.mjs`

## Failure

Items are closed with --version 0.7.27 during release preparation, before the release is published. wf improve list then shows them as closed and fixed in 0.7.27 while the marketplace still installs 0.7.26 and the running engine is 0.7.26. A person or session reading the list concludes the fix is available, runs the update, and still gets the old behaviour. The list and show output should compare the fix version with the running engine version and say when the fix is not released or not installed yet.

## Fix

wf improve list and show say 'not released or installed yet: this wf is X' beside a fix version newer than the running wf.
