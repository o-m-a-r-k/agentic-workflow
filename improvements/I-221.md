# I-221: A passing gate that reruns failed suites should carry the earlier run's screenshots

- **Class:** engine
- **Fixed in:** 0.7.32
- **Test:** `scenarios/run-screenshots.test.mjs`

## Failure

Gate 2026-10-18T09-48-58 of <ticket> passed by rerunning only the 2 suites that failed in run 09-17-35 and carrying 1251 tests from it; the 170 screenshots of that run were not attached to the passing gate, so <project>-e2e showed as uncovered for the evidence review (the reviewer opened the earlier run's files). A passing rerun that carries suites from a failed run should carry that run's captures for those suites.

## Fix

A run that carries suites from an earlier run carries that run's captures (sha-checked, marked carriedFrom); an evidence finding only a re-run of its gate step satisfies gets one plain wf gate on the unchanged tree.
