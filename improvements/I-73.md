# I-73: Filled registry secrets cannot provision dependencies before required precommit validation

- **Class:** engine
- **Fixed in:** 0.7.0
- **Test:** `scenarios/gate.test.mjs` (runs a command in the step)

## Failure

In <ticket>, the catalogued read-only registry token is filled, but wf run does not inject it and wf check refuses dirty worktrees before runtime dependency provisioning. Doctor skips plugin-only steps. Repository policy requires touched lint/tests before requesting a source commit, so a fresh frontend dependency directory creates a circular prerequisite. Provide a public, leased preparation-only provisioning operation that injects only usedBy secrets through the masked engine, preserves pinned install/runtime identity and task-owned cleanup, and never counts as gate evidence. This attempt uses an independently cloned matching-lock preparation cache with exact public native artifacts; final canonical install remains required.

## Fix

wf run --step runs the step's declared prepare with only the secrets the step uses, masked, and records no gate.
