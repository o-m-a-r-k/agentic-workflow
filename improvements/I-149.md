# I-149: A gate starts while an implementer is still committing

- **Class:** engine
- **Fixed in:** 0.7.11
- **Test:** `scenarios/gate.test.mjs`

## Failure

Audit of 51 attempts: gates started while implementers were still committing were stopped or thrown away.

## Fix

wf gate warns when an implementer is still open (a warning, never a refusal).
