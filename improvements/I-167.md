# I-167: Delta review bundle underreports files introduced by baseline merge

- **Class:** engine
- **Fixed in:** 0.7.30
- **Test:** `scenarios/fix-0730c.test.mjs`

## Failure

<ticket> reviewer31 bundle listed six changed files, but reviewer independently found and inspected41actualdeltafiles after a baseline merge. Compute delta changed-file inventory against the previous reviewed tree including merged baseline changes, matching the actual review range.

## Fix

delta.baseMerged lists the files only a base merge brought in; with delta.changed it is exactly the files of delta.diff, and the reviewer is told which is which.
