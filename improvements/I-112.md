# I-112: A lesson for a repo the attempt did not admit lands untracked in that repo's main checkout

- **Class:** engine
- **Fixed in:** 0.7.4
- **Test:** `scenarios/fix-074-lessons.test.mjs` (a lesson for a repository the attempt did not admit is refused with the route)

## Failure

wf lesson add with --repo naming a repo the attempt did not admit, or a project lesson whose adapter repo is not admitted, writes into that repo's main checkout as an untracked file even while the attempt is open.

## Fix

For attempts admitted at 0.7.4 or later, a lesson (or a moved lesson) for a repository the attempt does not hold is refused with the route (wf criteria amend --add-repo, or record it without --attempt on purpose) instead of an untracked file in that repository's main checkout; earlier attempts keep the write.
