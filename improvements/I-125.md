# I-125: Frozen admission validator cannot accept a reviewed forward correction

- **Class:** engine
- **Fixed in:** 0.7.8
- **Test:** `scenarios/validation-correction.test.mjs`

## Failure

A product repair changes a frozen browser assertion that incorrectly treats request failure as successful empty data and repairs native capture dimensions. Supplemental correction accepts only supplemental IDs and addition forbids an admission ID, so the full gate cannot execute corrected committed validation while preserving every original obligation. Add an audited owner-authorized forward correction path with unchanged check coverage, original and replacement pins retained, closed roles, clean source, fresh independent review and full gate; no manual evidence edits or skipped checks.

## Fix

wf validation correct may correct an admission step as the person's decision (override-gate), keeping the original definition in the record; a fresh review and the full gate follow.
