# I-76: Stale Codex manifest version prevents installation of released fixes

- **Class:** packaging
- **Fixed in:** 0.5.18
- **Test:** `scenarios/onboarding.test.mjs` (CLI, package and both host manifests must agree)

## Failure

The release changed the CLI and Claude versions while leaving Codex on the preceding version. Refreshing the marketplace succeeded, but the Codex installer reused its existing versioned cache and did not receive the released fixes.

## Fix

Keep both host manifests and the package version identical. Extend the existing release-version scenario to check Codex as well as Claude, so verification refuses a release with either manifest stale. Publish a new patch release without rewriting the existing release tag.
