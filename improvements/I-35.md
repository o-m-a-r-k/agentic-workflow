# I-35: Codex owner-session commands cannot close completed implementer handoffs

- **Class:** guard
- **Fixed in:** 0.5.3
- **Test:** `scenarios/owner-authority.test.mjs` (Codex owner-session command closes an implementer through direct and functions-exec records, once only)

## Failure

An adopted Codex owner ran the exact printed handoff-close command after the implementer committed and passed the required check, but ownerAuthority only accepts owner-session command evidence when runtime is claude. The error still offers the exact command alternative to Codex. Add host-verified Codex command provenance for bookkeeping closure without allowing child calls or forged tool results, and cover ordinary and functions-exec tool invocation records with a scenario test.

## Fix

Accept exact fresh one-use owner Codex shell calls, including one literal functions-exec wrapper, for implementer bookkeeping only. Reject subagent/headless metadata, forged outputs, mismatched commands and cwd, ambiguous code and replay.
