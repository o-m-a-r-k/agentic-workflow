# I-85: Reject admitting a page id as the ticket of a tracker with its own ticket identity

- **Class:** tracker
- **Fixed in:** 0.7.0
- **Test:** `scenarios/lifecycle.test.mjs` (ticket id before creating anything)

## Failure

wf entry accepted a document page id as the item, but the configured tracker names a ticket by its own key, normalised the capture to a ticket id, and refused the admission readback after the attempt had been provisioned. Validate the tracker identity before provisioning, so no attempt or role run is spent on it.

## Fix

wf entry checks the item against the tracker's ticket identity (built-in patterns or tracker.itemPattern) before anything is created.
