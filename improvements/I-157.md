# I-157: Bound shared runtime lease waits with fair queuing

- **Class:** engine
- **Fixed in:** 0.7.30
- **Test:** `scenarios/lease-fairness.test.mjs`

## Failure

<ticket> selection repair spent more than 35 minutes waiting for the Docker lease while other live runs repeatedly started containers. The implementation was ready and static checks passed. Expose queue position and use fair admission so small focused proofs cannot starve behind continuing gates; keep configured capacity and validation requirements intact.

## Fix

A free lease goes to the longest live waiter (marks refreshed while waiting, dead or stale marks ignored); each waiting run shows its place; principle 8 reworded to what it protects.
