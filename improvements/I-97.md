# I-97: Do not translate missing proof findings into committed diagnostic bundles

- **Class:** template
- **Fixed in:** 0.7.4
- **Test:** `scenarios/fix-074-texts.test.mjs` (proof is managed evidence, never committed to the repository)

## Failure

A reviewer correctly requested missing HTTP and visual evidence. The owner amended criteria to publish supplementary reports, captures and source hashes under a repository docs validation directory, then committed historical logs and replaced whitespace-heavy logs with gzip instead of excluding disposable outputs. Keep supplementary proof in managed evidence or tracker attachments; plans, reviewers and lessons must distinguish durable regression source from disposable run outputs and must not require Git commits merely for reviewability.

## Fix

The work skill, planner and implementer say proof is managed evidence, never committed; a scenario pins the wording.
