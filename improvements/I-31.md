# I-31: Adoption should accept the current chat human request

- **Class:** engine
- **Fixed in:** 0.5.1
- **Test:** `scenarios/adoption.test.mjs`

## Failure

Taking over an open attempt requires a release message from its previous owner session. A user in a new interactive chat cannot recover work when the previous session is unavailable, despite explicitly asking to adopt the ticket.

## Fix

Authorize adoption from the receiving interactive chat human request for a ticket or attempt, without the previous session. Preserve holds and work; record a one-use transfer receipt; reject headless, agent-generated, stale and replayed requests and closed attempts; make same-owner retries idempotent.
