# I-216: Analysis resume names an implementer which read-only intent refuses

- **Class:** engine
- **Fixed in:** 0.7.31
- **Test:** `scenarios/analysis-route.test.mjs`

## Failure

<ticket> analysis plan accepted with investigation-only work items; next output instructs implementer handoff, but handoff refuses: analysis attempts are read-only; only a planner handoff is allowed. Provide analysis evidence recording and completion route, and analysis-specific next output.

## Fix

An analysis attempt never names an implementer, gate or review: after its plan the investigation is recorded with wf analysis record (an answer with evidence per criterion, traced and not traced), then the person upgrades it (a fresh planner given the analysis) or closes it; its findings reach later planners and implementers, and it may run beside an open attempt of the item.
