# I-53: Frozen native reviewer instructions omit supported document reads

- **Class:** template
- **Fixed in:** 0.5.8
- **Test:** `scenarios/review-efficiency.test.mjs`

## Failure

A blind reviewer spent a full review using looped, wrapped and partial skill reads that could not establish a required-read receipt. Owner guidance documented the supported form, but the frozen bundle did not.

## Fix

Teach the supported literal full-file Node protocol in the frozen reviewer instructions and role template. Execute that documented form in a scenario and verify its exact output earns both rule and skill receipts; invalid reads remain rejected.
