# I-223: A correction can drop or narrow the admission step's declared reads

- **Class:** engine
- **Fixed in:** 0.7.33
- **Test:** `scenarios/correction-reads.test.mjs`

## Failure

Fable's re-check of 0.7.32: a correction that commits the admission step without its reads (or with a narrower glob) is accepted and nothing is pinned; the reviewer sees the definitions differ but the instruction calls paths plumbing and never names a shrunk declaration as a loss. The engine refuses a reads entry that matches nothing yet accepts one that vanishes. Corrected reads should still cover every file the previous pin covered, or the bundle should flag it as a loss.

## Fix

A corrected admission check records readsDropped: files an earlier pin covered that the corrected pin no longer holds; the reviewer judges each as a loss.
