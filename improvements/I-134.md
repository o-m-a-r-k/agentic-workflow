# I-134: Scope e2e gate steps to the specs a diff can affect

- **Class:** engine
- **Fixed in:** 0.7.30
- **Test:** `scenarios/affected-specs.test.mjs`

## Failure

A one-line <project> change reruns the whole 1,200-test <project>-e2e step (27-40 min). The gate has no way to run only the specs related to touched modules, so cost does not scale with change size and unrelated flaky specs block small fixes.

## Fix

A heavy step can declare affects rules; a standard attempt runs only the affected specs plus suites not passed last time, under their own key; any doubt runs the whole step with the reason.
