# I-98: Lesson writes fall back to main checkout after accepted attempt is amended

- **Class:** engine
- **Fixed in:** 0.7.0
- **Test:** `scenarios/lessons.test.mjs` (an accepted attempt reopened for repairs records its lesson in the worktree while an implementer is open)

## Failure

An implementer handoff for an accepted attempt with amended cleanup criteria called wf lesson add --repo <project> --attempt. targetFor rejected the attempt worktree because state.accepted was set and wrote an untracked lesson to the pull-only main checkout. The implementer moved the exact file into the assigned worktree, verified bytes, and removed the stray main file. Refuse or resolve the active amendment worktree instead of falling back to main.

## Fix

During repairs after acceptance a lesson is written to the attempt worktree, not the main checkout.
