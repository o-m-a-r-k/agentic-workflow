# I-199: Export interrupted-gate screenshots listed in evidence inventory

- **Class:** engine
- **Retired in:** 0.7.29
- **Refusals recorded:** none named

## Failure

After a browser gate is stopped following its first failed case, evidence list includes sealed named and failure screenshots, but export screenshots --gate refuses that the last gate collected no screenshots. The stopped result has an empty collected-artifacts list while files are sealed. Provide a supported export route for inventoried interrupted-run captures so implementers can diagnose them without relying on retained runner outputs.

## Why it was retired

Duplicate of I-198 (export screenshots of a named failed or stopped run), which stays open.
