# I-2: An over-broad delivered set can be narrowed once, with a reason

- **Class:** engine
- **Fixed in:** 0.1.14, 0.1.15
- **Test:** `scenarios/screenshots.test.mjs` (delivery narrow: the owner keeps the ticket's files of an over-broad set, once, with a reason; shown and the readback need only those)

## Failure

A delivered set of over a thousand files, a handful of them the ticket's, could only be finished by uploading all of them or editing the ledger.

## Fix

`wf delivery narrow --keep ... --reason`: once, before `wf shown`, ledgered; also for attempts delivered before the set was recorded.
