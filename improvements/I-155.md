# I-155: Frozen runtime onboarding should provide a supported pre-commit dependency preparation route

- **Class:** onboarding
- **Fixed in:** 0.7.30
- **Test:** `scenarios/prepare-route.test.mjs`

## Failure

An admitted runtime plugin provisions isolated private dependencies only during check/gate. The adapter has no declared prepare command; run --step therefore refuses, while check and gate --prepare-only reject uncommitted product changes. A clean baseline check skips every step as no changes. Required lint before source commit then needs a genuine structurally validated test/definition commit and a preparation check, preserving/restoring product edits. Detect and require a supported declared prepare route at onboarding/admission for runtime plugins with private dependencies, without arbitrary commands receiving secrets.

## Fix

wf run --step runs a plugin step's own prepare(ctx) at the attempt base under its lease with secrets masked; prepare: false declares none needed; doctor warns for a plugin step with neither.
