# I-211: A divided review can be started as a plain reviewer and is never recorded

- **Class:** engine
- **Fixed in:** 0.7.28
- **Test:** `scenarios/fix-0728b.test.mjs`

## Failure

A divided review bundle was started with a plain reviewer launch; its sub-reviews S1 and S2 were never created, the owner polled for about 80 minutes and the round was lost. A divided review should refuse a plain start or print only the wf handoff run line.

## Fix

A divided review prints only the wf handoff run line, and wf review parts refuses a group none of whose scoped reviewers was launched.
