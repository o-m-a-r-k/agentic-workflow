# I-45: Native role evidence reader rejects absolute handed paths

- **Class:** engine
- **Fixed in:** 0.5.5
- **Test:** `scenarios/evidence-read.test.mjs`

## Failure

A real native planner received an absolute bundle path but the sanctioned reader rejected it. Native reviewer document provenance also required absolute successful reads.

## Fix

Accept absolute paths confined lexically and by real ancestry to the selected attempt. Preserve no-follow, hard-link, cross-attempt, traversal, binary and image restrictions.
