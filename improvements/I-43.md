# I-43: Codex file-edit payloads are judged as shell commands

- **Class:** guard
- **Fixed in:** 0.5.5
- **Test:** `scenarios/codex-file-guard.test.mjs`

## Failure

The host supplies native patch text in tool_input.command. Shell heuristics rejected source regexes, role names and evidence citations although file targets were ordinary source files.

## Fix

Recognize only native apply_patch metadata, validate the patch protocol and inspect every file source/destination through existing target checks. Bash gets no patch allowance.
