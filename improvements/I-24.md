# I-24: Telemetry gaps: wf report undercounts findings and rounds, no cost, no sub-agents, no review-round or gate-stop events, no failing test names

- **Class:** engine
- **Fixed in:** 0.5.0
- **Test:** `scenarios/telemetry.test.mjs` (wf report counts every finding and repair round over several review rounds)
- **Commit:** 983d84f

## Failure

<ticket> retrospective: wf report showed 1 finding and 1 repair round for an attempt with 41 findings over 16 rounds, cost was blank, about 21 sub-agents of card-batch implementers were invisible, refused review rounds and gate stops left no record, and failing browser tests were recorded only as 'exit code 1'. Record: a review-round event (tree commit, gate state, reviewer model, outcome, commit behind each finding), a gate-stop event with reason and discarded minutes, implementer open/close events, parent handoff on sub-agents, scope change per criteria amendment (endpoints, codes, repos added), cost per handoff, and failing test names per gate step; fix the report's finding and round counts.

## Fix

wf report counts findings across every recorded review round and repair rounds as rounds that raised findings (gate failures separately); new ledger events review.round (incl. refused rounds), gate.stopped with reason class and discarded time, implementer.opened/closed via wf handoff close, subagents.attributed, scope.changed, failing test names per failed gate step; report shows phases, idle gaps, gate and round counts, tokens and cost per model and handoff (engine/prices.yaml, user and project overrides), and --json schema agentic-workflow/report@1
