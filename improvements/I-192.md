# I-192: Shipped task closure cannot recognize explicit owner chat authorization

- **Class:** engine
- **Fixed in:** 0.7.27
- **Test:** `scenarios/approve-question.test.mjs`

## Failure

<ticket> A12 remains pending after owner says ok we can close this then. wf approve A12 --from-question reports no matching answer despite the earlier exact question being quoted in this same chat. All source revisions were verified on target branches; manual override and merge already completed. Do not fabricate an approval. Need supported closure from the real owner answer.

## Fix

The agent reads the person's answer and records it with --choice and --quote; the engine proves the quoted words are verbatim from the person's own message in that session, written after the question, not superseded by a later reply, and that the choice is an option. Only exact answers bind by themselves (the panel's option, or a bare option to a message that asked the question and nothing else). Every recording is read back to the person. Codex harness items no longer end the asking message; a refusal never ends the turn; Done is set when the person asks or a label route sends it.
