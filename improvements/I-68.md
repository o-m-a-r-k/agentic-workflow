# I-68: Align legacy discovered-scope guidance with fixed issue verdicts

- **Class:** template
- **Retired in:** 0.7.0
- **Refusals recorded:** none named

## Failure

Fresh reviewer treated absent scope objects on all already-fixed legacy discoveries as a blanket blocker. Lifecycle documentation says missing metadata stays in scope for compatibility; scopeProblems explicitly skips absent scope and discoveredVerdicts requires current fix evidence. No supported command enriches existing discoveries. Clarify that missing metadata never waives an unresolved or extra-scope defect, but absence alone is not evidence a fixed legacy issue is unresolved or unauthorized. Add a scenario covering current fix verdicts for legacy discoveries and preserve causal classification for new extra findings.

## Why it was retired

Obsolete: 0.7.0 deleted the discovered-scope verdict check; a fixed discovered issue is never handed to a reviewer, and legacy waivers stay settled.
