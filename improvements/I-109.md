# I-109: Two evidence writes land outside the evidence transaction

- **Class:** engine
- **Fixed in:** 0.7.4
- **Test:** `scenarios/fix-074-lifecycle.test.mjs` (the rule copies of a reviewer bundle are written by the transaction)

## Failure

The reviewer rule copies (rules/<sha>-<doc>) are written while a full reviewer bundle is built, before the handoff is published, and the strategist bundle is written then appended with no transaction; a concurrent reader is refused with an extra-file integrity error until the writer finishes.

## Fix

every file a command writes into an attempt's evidence (rule copies, plans and amendments, reviewer, strategist and launch bundles, closures, summary, delivered comment, tracker captures and the engine's own readback, agent-reported readbacks, export page, imported captures, scope tickets, the issue copy) is now written and recorded in one transaction (recordedTogether, engine/ledger.mjs), prepareWrite refuses any other write, the tracker loop waits for the tracker before it writes, and wf verify waits for the lock
