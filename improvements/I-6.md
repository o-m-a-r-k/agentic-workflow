# I-6: The evidence guard and every path check agree with the OS

- **Class:** guard
- **Fixed in:** 0.1.17 to 0.2.1
- **Test:** `scenarios/guard-regressions.test.mjs` (guard is never more permissive than the 0.1.15 hook, on Bash and on file tools)

## Failure

Shell parsing to allow copies out of the evidence, lexical path checks, symlinks, hard links and races let writes reach the evidence or files outside it.

## Fix

A raw-text guard never looser than the frozen 0.1.15 hook; one canonical path resolver; no-follow, no-hard-link writes; a manifest verified at use. Also scenarios/integrity*.test.mjs, cli-paths.test.mjs, lessons-paths.test.mjs.
