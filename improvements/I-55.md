# I-55: Textual impact analysis hides truncation and ambiguous origins

- **Class:** engine
- **Fixed in:** 0.5.8
- **Test:** `scenarios/review-efficiency.test.mjs`

## Failure

At most 200 extracted names were analyzed without exposing symbol truncation. Equal names kept only the first declaration origin, and text occurrences were described as resolved consumers.

## Fix

Expose textual mode, extraction/structural limits, analyzed/total counts and separate truncation flags. Preserve every known origin for each analyzed name and mark ambiguous text matches. Existing closure fields remain valid.
