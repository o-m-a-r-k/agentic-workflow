# I-14: Reviewer handoff must print the agent name the review is bound to, and refuse early

- **Class:** engine
- **Fixed in:** 0.4.3
- **Test:** `scenarios/role-tools.test.mjs` (review provenance: an unnamed reviewer is accepted)

## Failure

wf handoff reviewer printed only 'Read <bundle> and follow its instructions' with no agent name (the implementer handoff prints 'name it X'). The reviewer ran unnamed, did the whole review, and wf review then refused the closure: no subagent transcript named rev-... A full round was lost. Print the name to use, and fail at handoff or accept the actual agent.

## Fix

Every handoff prints the agent type and the name to start it under (the reviewer's on stderr, its stdout stays the one start line); wf review and wf plan --from-agent accept an unnamed agent when exactly one unnamed transcript of the handed type began with this handoff's line after it (recorded identity: unnamed), and refuse none, several or another type with how to start it.
