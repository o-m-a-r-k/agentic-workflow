# I-222: Open visual evidence finding prevents the gate needed to review it

- **Class:** engine
- **Fixed in:** 0.7.32
- **Test:** `scenarios/deadlocks-0732.test.mjs`

## Failure

<ticket> latest clean code review records prior visual finding F3 open pending post-gate evidence review; wf gate refuses because F3 is not verified. Two fresh code reviews cannot close a proof obligation that requires a passed current-tree gate. Provide a route distinguishing pending evidence obligations from code blockers while preserving final evidence review.

## Fix

The gate order excuses a blocking finding an evidence round raised and a later round, handed no gate, kept open with evidence (only the gate's own proof can settle it); evidenceFixReady counts only criteria-changing amendments and the last implementer's outcome, so bookkeeping no longer forces a code review; a code finding kept open still blocks.
