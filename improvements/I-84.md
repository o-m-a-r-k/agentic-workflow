# I-84: Native planner replacements need immutable validation feedback

- **Class:** engine
- **Fixed in:** 0.7.0
- **Test:** `scenarios/impact.test.mjs` (a refused plan and its validator message are handed to the next planner only)

## Failure

Two native planner reports for <ticket> were rejected because survey component paths included repository prefixes while query results were repo-relative. A fresh handoff carries neither rejected plan nor wf plan refusal, and native prompt provenance forbids steering the launched process. Add a supported immutable feedback input for a fresh planner handoff; include prior unchanged report and validator errors, and require file-membership self-validation. Recovery currently requires superseding an attempt solely to provide corrected issue input.

## Fix

A refused plan is recorded with its raw report and validator message, and the next planner's bundle carries it.
