# I-4: Tracker readbacks are the raw tool output

- **Class:** tracker
- **Fixed in:** 0.1.16
- **Test:** `scenarios/handoff-quality.test.mjs` (delivered handoff: summary required, screenshots embedded inline, raw readback only, anomalies recorded, screenshots viewable after close)

## Failure

A readback rebuilt by hand (signatures stripped, the comment abridged) was accepted as proof of the handoff.

## Fix

A delivered readback must have the raw shape the tracker tools return and a comment equal to the rendered one; also covered by scenarios/gameday.test.mjs.
