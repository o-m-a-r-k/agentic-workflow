# I-57: Reports conflate unknown review history with wasted work

- **Class:** engine
- **Fixed in:** 0.5.8
- **Test:** `scenarios/review-diagnostics.test.mjs`, `scenarios/telemetry.test.mjs`

## Failure

An eventual recorded closure hid earlier refusals from the headline. Missing historical outcomes were inferred abandoned and labeled wasted. Native start failures were not clearly separated.

## Fix

Add counts for handoffs that experienced refusal, failed launches, failures before session start, and unknown superseded outcomes. Keep legacy fields and handoff deduplication. Reporting never mutates state or acceptance.
