# I-201: Support delivery to an additional divergent target branch

- **Class:** engine
- **Fixed in:** 0.7.30
- **Test:** `scenarios/delivery-targets.test.mjs`

## Failure

Accepted <ticket> targets master; user additionally requested staging. Adapter observes configured master only and entry help exposes no per-attempt target. Staging diverges; accepted-delta trial conflicted and its fixture verification failed, so it was discarded. Need documented supported route for separately reviewed staging integration without changing the global base or completed master delivery.

## Fix

wf entry --target bases and delivers on a named branch; --also-target or wf target add records extra targets, each delivered as a port attempt (own commits cherry-picked, frozen criteria) reviewed, gated and delivered like any attempt; a conflict is recorded, not hidden.
