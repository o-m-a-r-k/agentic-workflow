# I-230: Read-only replan check refuses frozen criteria

- **Class:** engine
- **Fixed in:** 0.7.34
- **Test:** `scenarios/amend-check.test.mjs`

## Failure

For <ticket> S2 consolidation, planner is required to run wf plan --check. Command refuses because criteria are already frozen and suggests the mutating wf criteria amend. Add a read-only amendment check or permit plan --check to validate a consolidated replan without recording it. No workflow rule was bypassed.

## Fix

wf criteria amend --check runs every check of the recorded amendment through the same path, against the adapter the record would follow, and records nothing; wf plan --check on frozen criteria names it.
