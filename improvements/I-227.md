# I-227: declaredReadsAt runs git rev-parse per file

- **Class:** engine
- **Fixed in:** 0.7.33
- **Test:** `scenarios/correction-reads.test.mjs`

## Failure

Fable's re-check of 0.7.32: a reads glob matching 300 files adds about 1 s to wf validation correct and each reviewer handoff, 0.25 s to wf resume. One git ls-tree -r <commit> gives path and blob in one call. Also: looksLoaded entries are unresolved raw strings including declared files; resolve and list only those outside reads.

## Fix

declaredReadsAt reads each tree with one ls-tree per process (keyed by resolved sha); looksLoaded resolves paths and reports only those outside reads.
