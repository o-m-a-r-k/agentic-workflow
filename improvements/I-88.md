# I-88: Refresh operational lease capacity without repinning test requirements

- **Class:** engine
- **Fixed in:** 0.7.4
- **Test:** `scenarios/fix-074-gate.test.mjs` (wf run --lease waiting on a full lease starts when the project raises the lease capacity)

## Failure

Existing attempts pin gate.leases to the admission adapter. A project capacity increase cannot unblock a queued check, and no supported operational capacity refresh exists. Separate resource capacity from frozen test definitions, with audited owner-authorized updates.

## Fix

wf run --lease re-reads the project's lease capacity while it waits, as a waiting check or gate does, and says who holds the slot and how capacity is raised
