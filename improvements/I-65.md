# I-65: Evidence guard mistakes a JavaScript object spread for a protected path

- **Class:** guard
- **Retired in:** 0.7.0
- **Refusals recorded:** none named

## Failure

While writing an ordinary owner-owned criteria-amendment helper under private tmp, the guard rejected a local flow variable spread named wf as if it targeted protected evidence. The command used only wf status for reads and wrote ordinary temporary JSON inputs; no protected path was named or targeted. Descriptive variable names resolved the false positive. Add a guard scenario for legitimate JavaScript object spreads without weakening actual evidence protection.

## Why it was retired

Obsolete: 0.7.0 removed the guard's Bash text scanning (334 refusals, none a write attempt); shell text, object spreads included, is no longer judged.
