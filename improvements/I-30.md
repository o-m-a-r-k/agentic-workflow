# I-30: Pre-push verification must clear repository-local Git environment

- **Class:** other
- **Fixed in:** 0.5.1
- **Test:** `scenarios/pre-push.test.mjs`

## Failure

The pre-push hook passes Git repository-local environment variables to the verifier. Scenario repositories then target the plugin Git directory, fail, and can change its branch and repository configuration instead of their disposable fixtures.

## Fix

Clear repository-local Git environment variables before running the full verifier. A real linked-worktree push scenario proves foreign fixtures use their own Git directories, source metadata stays unchanged, and failing verification still blocks the push.
