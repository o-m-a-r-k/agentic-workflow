# I-183: Manual delivery awaiting merge blocks base merge while deliver only observes

- **Class:** engine
- **Fixed in:** 0.7.26
- **Test:** `scenarios/base-merge-in-flight.test.mjs`

## Failure

QF11 manual GitLab adapter integrate returns MR URL and observe awaits merge. After first wf deliver, remote master advanced. wf base merge refuses already being delivered and says wf deliver merges base itself, but repeated wf deliver only observes and leaves task37commits behind. wf handoff implementer accepted for reconciliation; no plugin patch. Need supported base merge/repair route for manual adapters while awaiting merge, preserving fresh combined-tree review and gate.

## Fix

wf base merge brings a moved base into an attempt whose integration awaits merge; with a delivery adapter a base merge withdraws the acceptance (gate, evidence review, accept), and the next deliver re-integrates the reconciled branch.
