# I-135: Show a visible approval brief when the question panel is unavailable

- **Class:** skill
- **Fixed in:** 0.7.10
- **Test:** `scenarios/approve-question.test.mjs`

## Failure

For <ticket> A1, request_user_input_async returned accepted but the user reported no visible way to approve or reject. The assistant had provided file links and technical workflow wording instead of an inline decision brief. Present the exact action, reason, evidence and remaining checks in the final response; re-present the question and provide the supported human-terminal approval/rejection route when the panel is not visible. Tool acceptance is not evidence that the user can see the panel.

## Fix

A reserved decision is first explained in the agent's reply (what it does, why, what each choice leads to); a question with no recorded answer gives the terminal route, wf approve <id> --attempt <id>.
