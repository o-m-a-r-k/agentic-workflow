# I-100: Rebase plugin artifact paths when harvesting scratch output

- **Class:** engine
- **Fixed in:** 0.7.0
- **Test:** `scenarios/plugin-artifacts.test.mjs` (a plugin-produced screenshot goes gate, export --gate, review, acceptance and delivery)

## Failure

Gate plugin context gives only a scratch output directory, as intended. The gate hashes plugin-returned artifact paths and copies scratch bytes into managed storage, but retains original scratch paths in result.artifacts. Screenshot export then refuses every image as EOUTSIDE despite a passing gate. Rebase harvested plugin artifact references to their sealed managed copies and test a plugin-produced browser screenshot through gate, export and delivery; never weaken the outside-path guard or ask agents to write protected storage.

## Fix

Plugin artifacts are recorded at their sealed copies under the gate run, and older scratch paths map to them by sha256.
