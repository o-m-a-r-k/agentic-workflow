# I-189: Notion adapter writes delivery comments into the ticket description

- **Class:** tracker
- **Fixed in:** 0.7.27
- **Test:** `scenarios/tracker-attachments.test.mjs`

## Failure

Project operations.comment instructs heading_2 Agentic delivery page insertion; pageHandoffs normalizes description blocks as comments. README and adapter tests reinforce the wrong placement. Require real page comments and reject description sections as comment evidence; preserve screenshot attachments without silently using the description.

## Fix

Screenshots mode 'attachments' lets a tracker adapter post delivery handoffs as real comments with screenshots attached to comments; the project's Notion adapter now uses page comments (up to three screenshots on the handoff comment itself, more in follow-up comments) and never writes the ticket body.
