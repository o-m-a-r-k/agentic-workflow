# I-75: Claude-only tool instructions stop native Codex review completion

- **Class:** engine
- **Fixed in:** 0.5.17
- **Test:** `scenarios/codex-runtime-compat.test.mjs`, `scenarios/codex-run.test.mjs`, `scenarios/codex-node-reads.test.mjs`

## Failure

A native Codex reviewer was instructed to use Claude's Write tool for its closure despite having an equivalent writer. Shared instructions also demanded Claude-only document, skill, image and messaging tools, and a parent-session restart for fresh native launches. Successful command reads through the current tool transport did not establish document receipts.

## Fix

Teach host-supported alternatives across generated roles, native role instructions and owner skills. Limit every closure writer to the handed closure file. Preserve full inspection, complete-output document reads, evidence protection and the reviewed tree. Recognize only completed literal command reads whose actual output contains the complete file. Use fresh native handoffs rather than attempting to message finished processes.
