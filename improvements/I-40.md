# I-40: Codex functions-exec connector readbacks are ignored

- **Class:** tracker
- **Fixed in:** 0.5.3
- **Test:** `scenarios/tracker-host-recorded.test.mjs` (Codex connector readbacks accept a single literal functions-exec call and native Linear aliases)

## Failure

Host-recorded tracker readback ignores custom_tool_call and custom_tool_call_output even for a single literal connector call with an unchanged printed result. Native prefixed Linear tool names also fail canonical tool matching. Support only structurally provable one-call wrappers and refuse arbitrary scripts.

## Fix

Read native Linear tool aliases and single literal functions-exec connector calls matched to unchanged completed-script results. Refuse transformed, multiple, conditional, mismatched and errored outputs.
