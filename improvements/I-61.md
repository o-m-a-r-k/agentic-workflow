# I-61: Generated AGENTS Markdown reintroduces formatter errors on sync

- **Class:** onboarding
- **Fixed in:** 0.5.10
- **Test:** `scenarios/onboarding.test.mjs` (I-61: generated Markdown separators survive repeated sync without altering authored text)

## Failure

The generated block omits a blank line after its opening HTML marker and before the Rules list. The canonical Markdown formatter adds both lines; a subsequent sync regenerates the unformatted block. Preserve formatter-compatible separators, surrounding authored text and sync idempotence without changing workflow policy.

## Fix

Preserve the formatter-compatible blank lines after the generated opening marker and before the Rules list; regression covers initial generation, two syncs, one block and surrounding authored text without changing policy.
