# I-231: Frozen-plan amendment lacks a supported dry-run path

- **Class:** engine
- **Fixed in:** 0.7.34
- **Test:** `scenarios/amend-check.test.mjs`

## Failure

<ticket> planner13/15 impact checks passed but wf plan --check refuses frozen criteria before amendment schema checks. Owner wf criteria amend then exposes missing query provenance in4contract entries, requiring another native planner handoff for a schema-only repair. Provide a supported read-only criteria-amend check using the same validator, so planner catches this before handback; do not weaken contract provenance or edit plugin from a ticket.

## Fix

A planner re-planning frozen criteria dry-runs the amendment with wf criteria amend --check before handing back, so provenance and schema errors surface before the owner records it.
