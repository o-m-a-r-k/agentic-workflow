# I-51: Quoted search regex is mistaken for an evidence glob outside project scope

- **Class:** guard
- **Fixed in:** 0.5.7
- **Test:** `scenarios/trust-0.7.test.mjs` (0.7.0 removed the check this fixed, with the test that proved it; see docs/trust-model.md)

## Failure

A literal read-only source search is refused because its quoted regex is classified as a possible evidence path. Preserve actual cross-project evidence protection while recognizing a bounded safe search form.

## Fix

Recognize one literal quoted-regex search outside protected scope; keep original evidence checks, canonical single-link regular-file operands, option parsing and conservative fallback.
