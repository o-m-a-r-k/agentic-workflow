# I-58: Native reviewer applies full-file document receipts to the large JSON handoff

- **Class:** template
- **Fixed in:** 0.5.9
- **Test:** `scenarios/review-efficiency.test.mjs` (I-58: large handoffs use bounded structured inspection without earning document receipts)

## Failure

In 0.5.8, a native reviewer printed a 2.75 MB frozen handoff in one tool result, received truncated output, and stopped without recording a closure. A fresh retry repeated the failure. The reviewer misapplied complete required-document receipts to the structured JSON handoff and requested a smaller bundle. The startup role and frozen instructions needed an explicit distinction between bounded handoff inspection and full-file reads of separate required documents.

## Fix

Separate structured JSON handoff inspection from complete document receipts in the frozen instructions and native bootstrap; inspect all required sections in bounded batches without discarding evidence or granting document-read credit.
