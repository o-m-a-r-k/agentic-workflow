# I-60: Reviewer formatter alias mutates the settled source tree

- **Class:** template
- **Fixed in:** 0.5.10
- **Test:** `scenarios/codex-run.test.mjs` (I-60: reviewer command safety reaches generated roles and native launch; check-only alias preserves tracked bytes)

## Failure

A native evidence reviewer invoked yarn prettier --check without inspecting the package alias; it expanded to prettier --write . --check and reformatted three tracked source files. Review correctly refused, restoration preserved the original code review and gate, but a fresh evidence round was required. Evaluate minimal command-safety guidance or prevention without weakening review refusal.

## Fix

Teach reviewers to inspect validation scripts, wrappers and relevant lifecycle hooks before invocation; prefer explicit check-only commands and reuse sufficient gate evidence. Appended check flags never establish absence of writes. Preserve changed-tree rejection and report unclear commands to the owner without repairing files.
