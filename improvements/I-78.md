# I-78: Verification reports success for a missing selected attempt

- **Class:** engine
- **Fixed in:** 0.7.4
- **Test:** `scenarios/fix-074-gate.test.mjs` (an emptied ledger is reported by verify, resume, status)

## Failure

During <ticket> recovery, the populated evidence directory had accidentally been renamed and the original directory was empty. wf status --json returned [], and the reviewer could not resolve the attempt, but wf verify --attempt <ticket> returned verified 1 attempt(s). The verifier treats an empty ledger as pre-manifest without first requiring the explicitly selected attempt to exist. Require an actual selected attempt and ledger before reporting verification success. After the human-authorized folder restoration, the real populated attempt verified successfully.

## Fix

a ledger with no entry is a reported integrity problem in verify and every command that opens the attempt (the anchor checks no longer depend on a head entry), wf status and status --all name the attempt instead of crashing, and wf verify --all names an attempt whose ledger is gone while its anchor survives
