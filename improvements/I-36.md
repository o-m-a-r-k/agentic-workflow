# I-36: Doctor validates Claude models while running in Codex

- **Class:** onboarding
- **Fixed in:** 0.5.3
- **Test:** `scenarios/onboarding.test.mjs` (doctor validates planner and reviewer models for the selected Codex runtime)

## Failure

Doctor reports model readiness from Claude class pins even in Codex, so Codex planner/reviewer inheritance is hidden and a Codex-only pinned configuration is judged against the wrong runtime.

## Fix

Doctor validates model pins and inheritance warnings for the current or explicitly selected runtime; Claude pins cannot satisfy Codex readiness.
