# I-29: Runtime model settings must not require a plugin release

- **Class:** engine
- **Fixed in:** 0.5.1
- **Test:** `scenarios/classes.test.mjs` (wf sync preserves current and future runtime model and effort strings without a plugin update)

## Failure

The static effort allow-list rejects settings supported by the host, so a new effort level requires a plugin release even though model identifiers are already open.

## Fix

Remove the static runtime effort allow-list. Preserve model and effort strings in generated agent metadata, reject malformed values, and delegate supported combinations to each host.
