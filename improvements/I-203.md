# I-203: A '?' the agent appends to a legacy question, or a panel offering a legacy decision's frame labels, costs an extra agent command

- **Class:** engine
- **Fixed in:** 0.7.28
- **Test:** `scenarios/approve-question.test.mjs`

## Failure

After 0.7.27's check that a bare yes/no binds only to a message that asked nothing else: a legacy decision (no labels) whose question the agent writes with an appended '?' ('<ticket> A1: close <ticket> as shipped without its acceptance?') refuses the person's bare yes, in chat and panel; the agent then records it with --choice yes --quote yes (one extra command, never the person). A panel offering a legacy decision's frame labels is refused by offered() with no read hint. The read hint says 'your message' for a panel question too. Fix: ignore a '?' immediately after the question text; let offered() accept frame labels; word the hint for panels.

## Fix

A '?' right after a question that starts its own sentence is the question's own mark; a panel accepts a legacy decision's frame labels; the hint is worded for panel questions.
