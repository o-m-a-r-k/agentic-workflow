# I-46: Native Codex launch rejects a configured project root outside Git

- **Class:** engine
- **Fixed in:** 0.5.5
- **Test:** `scenarios/codex-run.test.mjs`

## Failure

The real adopted project has independent Git repositories under a parent project folder. Model refresh and attempt-aware doctor passed, but native reviewer launch rejected that parent before starting a reviewer session.

## Fix

Validate every recorded Git worktree as a repository root and reject replaced Git objects. Only for a project root outside Git, pass Codex's supported `--skip-git-repo-check` option. Keep the workspace-write sandbox, exact start prompt and pinned role settings. Validate before recording a launch; the protected receipt names the actual root, sandbox and Git-root option. No fake parent repository or evidence edits.
