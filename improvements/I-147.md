# I-147: Rules copied into projects' AGENTS.md go stale between syncs

- **Class:** engine
- **Fixed in:** 0.7.11
- **Test:** `scenarios/onboarding.test.mjs`

## Failure

Two projects carried the pre-0.7.8 rule medium is your judgement in AGENTS.md three releases later, because the block was refreshed only by a wf sync nobody ran; an agent escalated the contradiction to the person.

## Fix

The AGENTS.md block points to the plugin's rules instead of copying them; generated files git does not track are refreshed to the installed plugin at a handoff; stale tracked ones are named in wf resume with the fix.
