# I-120: Implementation amendments leave inherited analysis-only plan narrative active

- **Class:** engine
- **Fixed in:** 0.7.10
- **Test:** `scenarios/dead-ends.test.mjs` (I-120)

## Failure

<ticket> began as analysis and was explicitly upgraded to implementation; same-ticket split siblings retain the original state.plan contract saying no code or delivery while criteria/work/impact amendments freeze native implementation. Current criteria-amend CLI ignores top-level plan/contract fields, so implementer bundles require owner reasons to explain conflicting historical narrative. Present the latest scoped contract and stage intent coherently, retaining original plan history without treating stale no-implementation prose as active authority.

## Fix

An amendment restates plan sections (what they replaced kept in planHistory); implementer and reviewer bundles carry intent, intentChanges (a split sibling inherits its parent's), splitFrom and a planNote when the plan's narrative predates what the attempt is for.
