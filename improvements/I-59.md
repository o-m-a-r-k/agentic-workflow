# I-59: Unchanged role waits produce repetitive liveness messages

- **Class:** engine
- **Fixed in:** 0.5.10
- **Test:** `scenarios/role-progress.test.mjs` (I-59: a quiet hour emits one heartbeat per ten checks without invented progress)

## Failure

An owner repeatedly posts the same pending-review status while a native role runs, consuming chat space without new progress. The CLI also prints liveness once per minute. Suppress unchanged status between ten eligible checks, retain one occasional liveness heartbeat, and report launch, meaningful progress, terminal outcomes, failures and required actions promptly. Waiting guidance must avoid repeated worktree/model/next-step summaries and preserve host-mandated notification requirements.

## Fix

Keep nine eligible native-role checks silent and emit one liveness heartbeat on the tenth; guide owners to report genuine changes promptly without repeating unchanged status, while respecting mandatory host updates.
