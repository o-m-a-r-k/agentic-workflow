# I-136: Any app-code change reruns a whole e2e step: the gate cannot tell which suites a change reaches

- **Class:** engine
- **Retired in:** 0.7.10
- **Refusals recorded:** none named

## Failure

Suite-level reuse (0.7.6) carries passing suites only when nothing but suite files changed (gate.mjs suitesToRerun: any other input change reruns the step whole). A one-line change to a page that three specs visit costs the full <project> e2e run (27-40 minutes on one project), the same as a change on the startup path of every page. The owner agent told the person the gate is all or nothing per step. Proposed: a step may report which source files each suite executed (per-suite coverage); a suite whose executed files are all unchanged carries its pass, an input no suite's map attributes reruns the step whole.

## Why it was retired

Duplicate of I-134 (choosing the e2e specs a change can affect), which stays open with a static estimate of about 5 minutes saved per 35-minute run on one project.
