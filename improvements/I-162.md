# I-162: Retain stopped gate failure details in repair handoffs

- **Class:** engine
- **Fixed in:** 0.7.30
- **Test:** `scenarios/fix-0730c.test.mjs`

## Failure

The subsequent implementer handoff 07 had gate:null and no failedGate/findings. Preserve the failed step and artifact references from a stopped run so repair agents receive the demonstrated cause without owner reconstruction.

## Fix
