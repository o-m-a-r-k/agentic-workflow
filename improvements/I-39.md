# I-39: Codex planner import can consume an unrelated Claude transcript

- **Class:** engine
- **Fixed in:** 0.5.3
- **Test:** `scenarios/field-fixes.test.mjs` (Codex planner import never borrows a same-named Claude transcript)

## Failure

A Codex planner handoff is marked unverified but plan --from-agent still searches Claude subagent transcripts by name and can freeze an unrelated runtime output. Refuse cross-runtime fallback and explain the host plaintext limitation.

## Fix

Codex planner import cannot use a Claude transcript. Import verified engine-launched native Codex output unchanged, or require the original reply file with unverified provenance.
