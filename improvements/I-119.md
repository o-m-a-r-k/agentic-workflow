# I-119: The base branch can carry changes no gate proved, and nothing says so

- **Class:** engine
- **Fixed in:** 0.7.8
- **Test:** `scenarios/decisions-per-item.test.mjs`

## Failure

A change was merged to the base branch by hand after 18 gates, none of which passed. The next attempt's gate failed with 617 end-to-end failures that all reproduced on the base branch; the owner learned that only from an investigator run after the gate, and the repair of the base branch's failures was done inside that attempt. Neither wf resume nor wf gate says that the base branch moved through commits no workflow delivery or passing gate covered, which would tell the owner before the gate that failures may come from the base.

## Fix

wf resume names the commits the base gained that no workflow delivery of the project covered, so a gate failure that comes from the base is visible before it costs an investigation.
