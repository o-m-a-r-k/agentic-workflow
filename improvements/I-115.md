# I-115: A legacy attempt with one scoped and one unscoped implementer reads as work not started

- **Class:** engine
- **Fixed in:** 0.7.4
- **Test:** `scenarios/fix-074-lifecycle.test.mjs` (on a legacy attempt, an implementer handed without --work covers every item no scoped handoff names)

## Failure

On an attempt admitted before 0.7.0, an implementer handed with --work and a later one handed without it leave the other work items unstarted for ever.

## Fix

on an attempt admitted before 0.7.0 an unscoped implementer covers every work item that existed when it was handed and no scoped handoff names; items an amendment adds later stay unstarted (a relaxation, for every attempt)
