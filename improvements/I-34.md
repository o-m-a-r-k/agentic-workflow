# I-34: Codex transcript lookup ignores the active indexed rollout

- **Class:** engine
- **Fixed in:** 0.5.2
- **Test:** `scenarios/adoption.test.mjs` (Codex adoption reads the active indexed suffixed rollout rather than the stale initial transcript)

## Failure

A resumed desktop chat records current human requests in a suffixed rollout selected by the host thread database. Filename-only lookup reads an older rollout and refuses valid adoption.

## Fix

Read the active Codex rollout from its read-only host thread index, validate transcript path and session identity, and refuse invalid indexes without stale fallback.
