# I-15: Role agent files are only loaded at session start, so a wf sync that fixes a role does not reach agents started in the same session

- **Class:** template
- **Fixed in:** 0.4.3
- **Test:** `scenarios/role-tools.test.mjs` (wf sync names the role files it changed)

## Failure

After wf sync added Write to the wf-reviewer tools list, the next reviewer in the same session still had Write disabled and fell back to a shell heredoc. Say so after wf sync, or have the handoff warn when the loaded role differs from the generated file.

## Fix

wf sync rewrites a role file only when its content changes, lists the changed role files and says a running session keeps the roles it loaded; wf handoff warns when the agent type's role file changed after the owning Claude Code session started (the later of its transcript's first entry and its process start).
