# I-170: Screenshot export refuses repeated titles from multiple gate suites

- **Class:** engine
- **Fixed in:** 0.7.20
- **Test:** `scenarios/fix-0720.test.mjs`

## Failure

A passing gate collected captures with identical source-relative names from different suites. gateFiles produces repeated titles and exportScreenshots refuses the entire set before any screenshot can be reviewed. Preserve every recorded artifact and integrity check while assigning deterministic collision-free exported names; cover same and different byte captures from multiple suites.

## Fix

Same fix as I-161: repeated titles across suites export under distinct names.
