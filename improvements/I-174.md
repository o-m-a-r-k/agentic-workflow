# I-174: Chat approval reader selects clarification instead of latest explicit yes

- **Class:** engine
- **Fixed in:** 0.7.28
- **Test:** `scenarios/approve-question.test.mjs`

## Failure

On <ticket> A3, the engine question was quoted exactly in a final message. The user asked for explanation, received it, and then answered yes. Running wf approve A3 --from-question recorded the earlier clarification instead of the latest explicit yes. Validation correction then opened A4 and requires another user answer. Clarification handling must bind the subsequent explicit answer or provide a safe supported receipt selection route.

## Fix

Already fixed by 0.7.27's reading of replies: the person's latest reply to the question decides, so an exact yes after a clarification binds and the clarification is never recorded; the test is the proof.
