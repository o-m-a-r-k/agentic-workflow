# I-38: Codex usage reporting duplicates resumed rollouts and token categories

- **Class:** other
- **Fixed in:** 0.5.3
- **Test:** `scenarios/telemetry.test.mjs` (Codex usage reads the active indexed rollout and native thread snapshots without retained-rollout duplication)

## Failure

Usage sums every filename containing a session id, including retained old rollouts, ignores native token_usage_record snapshots, bills cached input as uncached too, and adds reasoning output twice.

## Fix

Read one active indexed rollout and native thread usage snapshots. Normalize cached input and reasoning as subsets instead of billing twice, and never sum retained rollout copies.
