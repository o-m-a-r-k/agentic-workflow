# I-87: Native planner retry loses validation refusal

- **Class:** engine
- **Fixed in:** 0.7.0
- **Test:** `scenarios/impact.test.mjs` (a refused plan and its validator message are handed to the next planner only)

## Failure

A rejected planner output used repository-prefixed component paths. A fresh native planner handoff does not include the refused plan or validation errors, preventing the documented corrective retry from receiving its repair context. Add prior planner refusal context to fresh planner bundles without steering independent reviewers.

## Fix

Same fix as I-84: the planner retry is handed the refusal.
