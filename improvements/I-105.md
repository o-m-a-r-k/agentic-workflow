# I-105: A shell left standing in the evidence folder could run nothing, not even cd out of it

- **Class:** guard
- **Fixed in:** 0.7.3
- **Test:** `scenarios/guard-regressions.test.mjs` (a shell standing inside the evidence can leave it with a bare cd, and nothing else runs there)

## Failure

An agent ran cd into the attempt's evidence folder and ls in one Bash command; shell text is not scanned, so it passed, and the shell's working directory stayed there. The working-directory rule then refused every later command, cd back out included: 18 refusals, the session could run nothing, and its ticket stopped.

## Fix

From inside the evidence folder the guard lets a bare cd to a folder outside it pass; every other command there is still refused, and the refusal says how to leave.
