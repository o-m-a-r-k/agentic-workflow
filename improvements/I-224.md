# I-224: Transitive loads of a declared harness are invisible to the correction review

- **Class:** template
- **Fixed in:** 0.7.33
- **Test:** `scenarios/correction-reads.test.mjs`

## Failure

Fable's re-check of 0.7.32: a declared harness that imports ../support/commands.js: editing that file never re-asks the verdict and looksLoaded lists nothing (it scans the plugin only). The reviewer instruction should name what a declared file itself imports and the spec tree a runner picks up; projects can declare a wider glob.

## Fix

The reviewer is told a declared file's own imports and the runner's spec tree belong to the check; looksLoaded scans declared files and lists resolved paths outside reads as a hint.
