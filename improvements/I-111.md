# I-111: Admission-time provisioning runs without the secrets a private install needs

- **Class:** engine
- **Fixed in:** 0.7.4
- **Test:** `scenarios/fix-074-gate.test.mjs` (a catalogued key that lists provision:<repo> in usedBy reaches that repo)

## Failure

provision.install at wf entry runs with the project environment only, never with catalogued secrets, so an install that needs a registry token fails at entry; only the gate's prepare path receives a step's secrets.

## Fix

a catalogued key that lists provision:<repo> in usedBy reaches that repo's provision.install at wf entry (masked in its failure output, refused up front when unfilled) and nothing else; documented in the adapter docs
