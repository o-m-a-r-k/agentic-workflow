# I-96: Supplementary validation manifests inflate full-review workload

- **Class:** engine
- **Fixed in:** 0.7.4
- **Test:** `scenarios/fix-074-lessons.test.mjs` (documentation files neither weigh on the division)

## Failure

<ticket> required durable supplementary HTTP results and four captures because the frozen gate did not collect them. The resulting documentation-only provenance package inflated review division to 50 files and 29378 changed-line cost, with 49 files assigned to integration and 36 unmapped, although runtime source was unchanged. Provide a supported immutable supplementary-evidence ingestion path, hand it to fresh reviewers, and distinguish provenance manifest entries from executable product declarations without weakening mandatory review or test execution.

## Fix

Documentation and provenance files (prose by extension, docs folders, LICENSE and NOTICE, and a caller-supplied matcher for an adapter's docsOnly) no longer count toward a review division's 40-file threshold, cost, unmapped-integration count or flows; the integration reviewer still owns and is handed every one, the plan lists them under documentation, and the final-diff symbol scan takes no declarations from them.
