# I-13: Reviewer role lacked the Write tool its instructions require

- **Class:** template
- **Fixed in:** 0.4.0
- **Test:** `scenarios/role-tools.test.mjs`

## Failure

The generated reviewer was told to write its closure with the Write tool, but its tools list was Read, Grep, Glob, Bash, so the closure could not be recorded and a review round was lost.

## Fix

Each role's tools come from one list (the reviewer gets Write and Skill); a scenario parses every generated role and fails when its instructions name a tool it lacks; the reviewer may write only its closure file, and wf review refuses a closure when the worktree changed during the round.
