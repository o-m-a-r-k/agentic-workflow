# I-206: Delta reviewer handoff omits newly added supplemental validation

- **Class:** engine
- **Fixed in:** 0.7.29
- **Test:** `scenarios/supplemental-validation.test.mjs`

## Failure

In wf 0.7.27, batch BATCH-<ticket> ledger seq34 records validation.added with six steps at 2026-10-17T14:40:16.816Z before reviewer handoff03. The delta bundle supplies supplementalValidation: [] because lifecycle.mjs:942 includes only correctedFrom records. Reviewer retained an activation finding based on that empty field until the owner supplied the missing event. Supported wf gate --prepare-only --full independently selects all six steps as run. Include additions since the last reviewed round as well as corrections, and require their pinned-definition review verdicts. This is a handoff omission; runtime registration works.

## Fix

A delta bundle carries every check registered, corrected or carried since the last recorded review, and the reviewer is asked for a verdict on each pinned definition.
