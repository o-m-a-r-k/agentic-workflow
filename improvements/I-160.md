# I-160: Export imported current-tree diagnostic captures before a full gate or delivery

- **Class:** engine
- **Fixed in:** 0.7.30
- **Test:** `scenarios/run-screenshots.test.mjs`

## Failure

Current-tree captures import succeeds, but export screenshots refuses not delivered and export screenshots --gate reports no last-gate screenshots. User explicitly waived full gate while retaining independent review. This prevents the documented exported-image review route for real imported diagnostic proof; support exporting current-tree imports with provenance without fabricating gate acceptance.

## Fix

Imported captures export by name before any gate (wf export screenshots --run import-<n>).
