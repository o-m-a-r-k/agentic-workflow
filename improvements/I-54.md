# I-54: Identifier suffix mistaken for an assembled evidence fragment

- **Class:** guard
- **Fixed in:** 0.5.8
- **Test:** `scenarios/trust-0.7.test.mjs` (0.7.0 removed the check this fixed, with the test that proved it; see docs/trust-model.md)

## Failure

A documentation-edit heredoc containing Markdown `resultEvidence` was refused by the standalone trailing-fragment predicate.

## Fix

Require a left identifier boundary before the trailing fragment, consistent with the existing glued-fragment convention. No interpreter exemption is added. Preserve standalone assembly, explicit/split/escaped/globbed protected paths, protected working directories, and the frozen regression corpus.
