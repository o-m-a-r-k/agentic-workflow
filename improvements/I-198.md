# I-198: Export failed-step screenshots for implementer diagnosis

- **Class:** engine
- **Fixed in:** 0.7.30
- **Test:** `scenarios/run-screenshots.test.mjs`

## Failure

<ticket> failed browser step retained four failed-case screenshots listed by wf evidence list, but wf export screenshots --gate reports that the last gate collected no screenshots. Role instructions require exported image copies for viewing; expose a sanctioned failed-artifact export route.

## Fix

wf export screenshots --run <run|import> copies every image a run or import recorded (failed, stopped, interrupted, recovered), sha-checked; empty refusals name where images are; failedGate names the command.
