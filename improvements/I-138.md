# I-138: Legacy selected-step admission markers block every check and correction

- **Class:** engine
- **Fixed in:** 0.7.11
- **Test:** `scenarios/validation-correction.test.mjs` (earlier recorded shape)

## Failure

A reviewed local admission correction recorded admission:true on selected steps and preserved the original definitions in from without an admission field. Current gateAdapter recognizes only from[].admission. It therefore refuses both check and validation correct before any safe forward correction can be requested. Preserve historical records and verified committed definitions, admit only the exact authorized legacy shape, and retain reserved owner approval for all new admission corrections.

## Fix

An admission correction recorded by an earlier build (the corrected step marked admission, the original in from unmarked) counts as one; an admission step replaced with no mark is still refused; the engine writes only the current shape.
