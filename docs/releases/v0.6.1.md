## 0.6.1 - Automatic review division by default

- Fresh reviewer handoffs and foreground advancement automatically divide large changes with separable recorded
  flows into scoped reviews plus integration. Small, ambiguous, mostly shared or highly unbalanced changes keep
  one reviewer. This fixes ordinary handoffs silently retaining a serial review unless the owner remembered a flag.
- `--single` explicitly keeps one reviewer for fresh rounds. `--reviewers 2|3` works without an activation flag;
  `--parallel` remains a compatible alias for automatic selection. Conflicting selectors and invalid values are
  refused before handoff creation or advancement. Existing handoffs retain their recorded assignments.
- Work, quick-fix and resume instructions use automatic selection and launch a returned group through its one
  integration handoff. Scoped reports, all findings, frozen runtime settings and integration coverage retain the
  existing enforcement and review/gate order.

Scenarios reproduce the former default, check both handoff and foreground automatic selection, the explicit single
override, existing-round preservation and concurrent scope execution before integration. Runtime fixtures prove
execution and evidence enforcement; real model speed and defect recall remain unbenchmarked.
