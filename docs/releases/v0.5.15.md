## 0.5.15 - Visible native review progress

- Native role launches relay completed assistant commentary to stderr as explicitly unverified agent reports. Owners can see the current review activity and preliminary concerns without inspecting the running transcript.
- Reports are bounded, stripped of terminal controls, deduplicated and coalesced to at most one per minute, with the newest pending report flushed at completion. Reasoning, tool outputs and terminal result payloads are never relayed as progress.
- Quiet roles retain occasional liveness heartbeats. JSON stdout, launch receipts, blind review, closure verification and acceptance remain unchanged.

Regression scenarios reproduce discarded commentary and cover native launch integration, both runtime event formats, output separation, control stripping, message flooding and quiet heartbeat behavior.
