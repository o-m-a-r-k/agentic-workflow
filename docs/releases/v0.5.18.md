## 0.5.18 - Consistent Codex and Claude installation versions

- I-76: the Codex plugin manifest now matches the Claude manifest and CLI package version. The preceding release left Codex labelled with an older version, causing its installer to reuse the older cache instead of loading the compatibility fixes.
- The release-version scenario now checks both host manifests against the CLI and package version. It fails when either manifest is stale.

This release contains the host-compatible tools and review completion fixes from 0.5.17. Upgrade the configured marketplace, then update/install the plugin for each host. Existing frozen review bundles remain historical; use a fresh handoff from the updated engine.
