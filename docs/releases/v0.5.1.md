## v0.5.1

Model and effort settings are open for both Claude and Codex (I-29). New host-supported models and effort levels no longer require a plugin release. Codex values such as max and ultra, and future runtime values, pass through unchanged to the generated agent files.

The host validates support for the selected model and effort combination. The plugin checks only that configured values are non-empty strings without control characters; omitted and null settings keep their inheritance behavior. Malformed values still fail configuration validation.

Regression scenarios prove the old restriction fails, current and future values survive agent generation, and malformed values are refused.
