## 0.5.14 - Preserve runtime and complete independent reviews

- Attempts record their originating runtime: Codex handoffs stay Codex and Claude handoffs stay Claude through adoption and recovery. Older attempts derive the default from their admission owner.
- A different provider requires explicit owner authorization for the selected handoff. Native launch refuses old mismatched handoffs without that authority; an interrupted, failed or incomplete review never causes an automatic provider switch.
- Reviewer instructions clarify legacy scope handling, require large reviews to continue to completion, and permit ordinary read-only inspection of indexed reference files.

Regression scenarios cover both runtime origins, admission host identity, legacy attempts, provider authorization, blocked mismatched launches, foreground recovery and reviewer instruction persistence.
