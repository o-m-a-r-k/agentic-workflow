## 0.6.3 - Complete bounded readers and combined workflow defaults

Large immutable handoffs can be inspected in bounded structured sections without requesting a reduced bundle.
Separate rule and skill documents still require complete, observed reads. This release includes the previously
local I-80 reader and bootstrap changes alongside automatic review division and state-folder protection.

- I-80 and I-81: complete bounded text pages preserve hashes, UTF-8 boundaries and full-document provenance.
  Structured sections never earn full-document read credit. Roles inspect every required section and continue
  oversized strings and collections through their returned cursors.
- I-80: the inspection limit includes final cursor metadata, pretty-printing and the trailing newline. Escaped
  strings and collections remain within 16 KiB on macOS and Linux without losing content between pages.
- I-82: numeric `evidence inspect --from` values reach pagination unchanged. The separate `skills update --from`
  option retains source-directory path validation, and inspection is confined to the evidence command.
- Reader instructions use the existing plain-command guard grammar. Quoted pointers, absolute executable paths,
  redirection and chained commands receive no new exception; existing guard and read-provenance guarantees remain.
- Both plugin manifests and the CLI package carry 0.6.3. Automatic parallel review selection remains the default
  for large, separable changes; small or coupled changes keep one reviewer and `--single` remains available.

Regression scenarios exercise real CLI pagination, guarded skill sources, complete string and collection recovery,
large handoff receipts, changed files, forged receipts, links and the frozen guard corpus. Real model review speed
and recall remain unbenchmarked.
