## 0.5.11 - Optional foreground advancement (local trial)

- `wf advance --once` and `--until-owner` use structured workflow decisions to run fresh native code review, the normal gate, fresh evidence review and acceptance. Both Claude Code and Codex are supported with frozen role/model/effort settings and verified native start prompts.
- The owning chat retains the execution handle and receives phase milestones plus a terminal result distinguishing process completion from recorded workflow validity. Findings, holds, failed or uncertain launches, missing closures, unresolved scope and owner decisions stop advancement. Delivery remains manual through the existing owner workflow.
- Full evidence integrity is checked between operations. Exclusive control locks never expire by age; external handoffs are never duplicated. Existing authorization, gate ordering, review coverage, model inheritance and same-round finding verification remain enforced.
- Scenario coverage includes both runtime paths, committed repairs, cancellation and concurrent runners, late evidence tampering, gate stops, missing owner identity, unstarted work and native Claude planner import.
