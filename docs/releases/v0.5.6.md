## 0.5.6 - Native launch diagnosis and Node document reads

- I-47: a permission-denied native app-server initialization before any session starts is recorded as a host initialization failure. The diagnostic requires a fresh handoff and approved host execution while preserving the child workspace-write sandbox. No automatic escalation, permission change or retry is performed.
- I-48: required documents and skills read through the native Node reader are recognized from literal host tool calls, leading unconditional full-file read/write expressions, and successful unchanged output containing the complete matching UTF-8 contents. Absolute paths and handed skill/invariant references bind the file. Missing, failed, truncated, wrong-path and ambiguous reads refuse; transcript JavaScript is never executed.
- A refused reviewer round still requires a fresh reviewer. Existing closures, prompts, frozen rules and evidence are unchanged.
