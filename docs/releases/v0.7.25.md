## 0.7.25 - `wf sync` says which files lost the old block

- **`wf sync` tells the block removal apart from the files it regenerates.** 0.7.24 said it had "removed the
  agentic-workflow block" from every file it wrote, listing the role files it regenerates on every sync (17 and 18 files
  in two projects) beside the one or two `AGENTS.md` files that held a block. An agent reading it could commit role files
  as block removals. It now lists the files a block was removed from, to commit, and the generated files separately.
